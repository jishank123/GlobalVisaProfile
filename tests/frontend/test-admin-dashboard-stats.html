Admin Dashboard Statistics Test

Expected Statistics:

  • Total Clients: Count of all client accounts in database
  • Active Projects: Count of assessments with status 'active', 'contacted', or 'converted'
  • Monthly Revenue: Estimated based on active projects × $2,500
  • Team Members: Calculated as max(5, clients ÷ 10)

API Endpoints Used:

  • GET /api/client-accounts/all - For total clients count
  • GET /api/profile-assessments - For active projects and assessments data
  • GET /api/contact - For contact submissions

Quick Links

Admin Dashboard Client Login (to create data) Profile Assessment (to create data)

Test Scenarios

  1. Create client accounts → Total Clients increases
  2. Submit profile assessments → Active Projects increases
  3. Change assessment status to 'active' → Active Projects updates
  4. Monthly Revenue auto-calculates based on active projects
  5. Team Members scales with client count

Note: Make sure the backend server is running on port 5000 and has data in the database before testing.
