1. **Super Admin** - Full system control
2. **CRM Manager** - Manage assigned clients
3. **Lead Handler** - Qualify and convert leads
4. **Client** - Self-service portal

### Core Features
- ✅ Service Management (CRUD operations)
- ✅ Client Assignment (Admin assigns to managers)
- ✅ Progress Tracking (0-100% with milestones)
- ✅ Payment Management (Tracking, reminders, installments)
- ✅ Query System (Client questions → Manager responses)
- ✅ Appointment Scheduling
- ✅ Analytics Dashboard
- ✅ Email Notifications

4. `service_milestones` - Progress checkpoints
5. `payments` - Payment tracking
6. `payment_reminders` - Automated reminders
7. `client_queries` - Support tickets
8. `query_responses` - Manager responses
9. `appointments` - Scheduled meetings
10. `chat_messages` - Real-time communication
